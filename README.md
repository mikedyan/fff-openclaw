# OpenClaw — Your AI, Unleashed

An interactive presentation showcasing [OpenClaw](https://github.com/openclaw/openclaw), the open-source AI agent framework.

**[View the presentation →](https://mikedyan.github.io/fff-openclaw/)**

## What's Inside

A single self-contained HTML file featuring:

- 🌙 **Sleep Coach** — AI accountability system with 5-level escalation
- 🏛️ **Council of Models** — Query Claude, GPT, Gemini & Grok in parallel
- 📰 **ClawTimes** — Automated daily AI news digest
- 📞 **Phone Calls** — Real phone calls via Twilio + ElevenLabs
- 🔱 **Sub-agents** — Spawn parallel workers for any task
- 🔐 **1Password** — Secure credential access
- 🍔 **Food Ordering** — DoorDash via one message
- 🪷 **Buddhist Teacher** — Talk to Thich Nhat Hanh (voice cloned)
- 🎙️ **Voice Cloning** — One video, one command, a perfect replica

## Navigation

- **Desktop**: Arrow keys, Space, or click the nav dots
- **Mobile**: Tap the ‹ › buttons, scroll within slides

## Tech

Zero dependencies. One HTML file. CSS animations, canvas starfield, and vanilla JS.
